## Планировка

План Суворина использован для сверки городской структуры. В игровой масштаб перенесены непрерывные фронты вдоль улиц, поперечные переулки, застройка набережных и разрывы у площадей, каналов и мостовых подходов. Дворовые размеры и положение корпусов рассчитаны по геометрии игровой сцены. [План Петербурга 1913 года](https://commons.wikimedia.org/wiki/File:Plan_SPB_Suvorin_1913.jpg) · [Каталог РГБ](https://search.rsl.ru/ru/record/01003132049)

На востоке, севере, юге и противоположном берегу Невы одиночные ряды заменены кварталами с задними и боковыми корпусами. Периметры включают дворы и служебные проходы. В пределах 118 фоновых кварталов застроено 81,2% суммарной площади участков. Фасады и крыши используют существующий генератор фона и MultiMesh. Экземпляры объединяются по материалу, уровню детализации и пространственной ячейке 96 м.

На участке INFILL_001 добавлена трёхэтажная пристройка с фасадом существующего купеческого дома. В INFILL_003 над проездом появился арочный корпус со скатной крышей. Коллизии арки следуют геометрии свода и опор. На участке INFILL_002 мощение западного подхода занимает основную часть поискового прямоугольника. Оставшаяся полоса нужна для подхода к торцу мастерской. Участки INFILL_004–008 сохраняют существующие корпуса и дворовые проходы. Координаты и результаты по всем зонам сохранены в [report.json](report.json).

За западным крылом Главного штаба добавлен трёхэтажный доходный дом. Корпус примыкает к зданию книжной лавки и оставляет свободными тротуар Невского и проход через арку. [Крупный план Дворцовой площади](after-palace-corner.png)

## Проверки

Экспортёр собирает геометрию сцены в мировых координатах. Для игровых зданий он использует AABB кладки и строительные коллизии, для фоновых — точные размеры кладки каждого экземпляра. Проезды и мощение определяются по поверхностям и треугольникам дорожных мешей. Связные участки свободной суши измеряются сеткой 0,5 м. Минимальный размер кандидата составляет 25 м². В списке свободной суши могут оставаться открытые пространства дальнего фона и территории с игровой функцией. Их площадь сама по себе не означает, что участок пригоден для строительства.

| Проверка | Результат |
|---|---|
| Пересечения фоновых зданий и новых контуров с дорогами или водой | 0 |
| Разрывы шире 3 м внутри фонового фасадного ряда | 0 |
| Проходы игрока через арку, вдоль сквера и по существующим маршрутам | 0 ошибок |
| NPC на протяжении 180 секунд, границы района, возврат после падения в воду | 0 ошибок |
| Общий валидатор геометрии | 31 замечание до и после |
| Тест дорожного трафика | 4 ошибки до и после |
| Тест городского вождения | 76 ошибок до и после |

Существующие замечания валидатора относятся к фонарям у Исаакия, проверке узла Невского и покрытию объезда. Ошибки транспорта на объезде воспроизводятся на исходной ревизии. На одинаковом общем плане число вызовов отрисовки выросло с 44 532 до 44 716, а число примитивов с 4,79 до 4,88 млн. Это измерение нагрузки на кадр в Godot 4.7.2 Compatibility с Mesa llvmpipe.

Для повторной генерации отчёта нужны Python с NumPy и SciPy.

```sh
godot --headless --script res://scripts/tools/export_infill_geometry.gd -- /tmp/infill-geometry.json
python3 scripts/tools/report_infill.py /tmp/infill-geometry.json
godot --headless --fixed-fps 60 --script res://scripts/tools/test_reconstructed_routes.gd
godot --rendering-method gl_compatibility --resolution 1600x900 --script res://scripts/tools/capture_infill.gd -- after
```
